# PulseWise Clinic

PulseWise Clinic is a full ReactJS frontend health system for the CSCI390 Web Programming Phase 2 project.

## Main Features

- Login and register pages
- Health risk prediction system
- Appointment booking with doctor, date, time, and reason
- Payment simulation with payment history
- Patient reviews with ratings
- Contacts page
- About Us page
- Responsive design for desktop and mobile
- Local browser storage for accounts, appointments, payments, and reviews

## How to Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

## Open Without Dev Server

The project includes a production build in the `dist` folder. You can open:

```text
dist/index.html
```

## Build for Deployment

```bash
npm run build
```

Upload the project to GitHub, then deploy it using GitHub Pages, Vercel, or Netlify.
